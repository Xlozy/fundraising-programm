Einstellungen

GitHub-Sync

Daten liegen als data-v2.json im privaten Repository fundraising-data. v1 schreibt data.json im selben Repo; diese Datei bleibt unberührt (N04). Token erstellen unter github.com/settings/tokens — «Contents: Read and write» auf das Daten-Repo genügt.

Unterlagen

Dokumente und Unterlagen verweisen auf Dateien mit einem Pfad relativ zu diesem Ordner. Der Ordner gilt nur auf diesem Gerät.

Export / Import

Export als Sicherung oder zur Übertragung. Import fügt Daten aus einer v2-Datei zusammen (gleiche ID = neuere Version gewinnt).

v1-Daten übernehmen

Einmalig: die Datei data.json aus v1 (Schema v5) wählen. Zuerst zeigt die App, was übernommen würde, mit Protokoll. v1 bleibt unberührt. Was es in v2 schon gibt, wird nicht verändert.
